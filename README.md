# not-fur-threejs

A small three.js demo of shell-based fur. The coat uses instanced shells, strand-length noise, dithered cut edges

This inspired from
[piellardj/fur-threejs](https://github.com/piellardj/fur-threejs).

## Use the live demo

go to this [live demo](https://riveramaxwell.github.io/not-fur-threejs/)

## Local run

Requires Node.js 18 or newer.

```sh
npm install
npm start
```
